Overview

The Project Gantt - Weekday Header module enhances the Odoo Gantt view by displaying full weekday names in group headers. This improvement provides clearer temporal context for project planning and scheduling activities.

  • Displays full weekday names in Gantt view headers
  • Improves readability with a format like Thursday, 10 July 2025
  • Helps project managers easily understand task timelines
  • Provides better temporal context for long-term projects
  • Seamlessly integrates with Odoo's native Gantt view

Ideal for project managers, planners, and teams that rely on clear and detailed scheduling in their Gantt charts.
