Server Monitor

Real-time monitoring dashboards for server resources, PostgreSQL, and Odoo health in Odoo 18. Track CPU, RAM, disks, network, GPU, DB activity, and Odoo operations with live charts and focused detail panels.

Key Features

  • Live charts for CPU, RAM, disks, network, and GPU utilization.
  • PostgreSQL dashboard with cache hit, connection usage, WAL, locks, and query insights.
  • Odoo dashboard with HTTP performance, workers, cron health, mail queue, and filestore stats.
  • Server log viewer with tail size and search filters.
  • Configurable alerts and persisted preferences in the UI.

Menus

Monitoring Server, PostgreSQL, and Odoo dashboards are available from the Monitoring menu. The Odoo menu includes a dedicated Server Log view.
