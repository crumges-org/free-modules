Implementation journey

  1. Install module and dependencies (`base`, `base_automation`, `social_media`).
  2. Create connectors per API (URL, auth, headers, companies).
  3. Define endpoints & transformations.
  4. Pair with server actions / automations / crons.
  5. Monitor logs and refine payloads.

FAQs

Does it overwrite data?

No. Each endpoint runs with configurable dry-run, validation hooks, and company scoping.

Is it multi-company?

Yes. You can assign connectors per company and map credentials per tenant.

Can Soltein implement it?

Yes, professional services are available for onboarding, SLAs, and custom automation.
