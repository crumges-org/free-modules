FAQ

Common questions

Everything you need to know before installing.

Is it really free? +

Yes. Modern Chatter is free and fully functional — no trial, no locked buttons. Chatter Pro is a separate paid module for teams that need filtering power tools.

What's the difference vs Chatter Pro? +

Modern Chatter gives you the modern UI, full-text search, reactions and stars. Chatter Pro adds type tabs with counts, author & date filters, pinned messages, a favorites filter and sort control.

Does it work on all models? +

Yes. Works on any model with a chatter — CRM, Sales, Invoices, Projects, Helpdesk, and more. Odoo.sh compatible.

Does it change how I send messages or manage activities? +

No. Only the message list view is replaced. The compose bar, Log Note, Send Message, Activities, and Followers widgets are completely untouched.
