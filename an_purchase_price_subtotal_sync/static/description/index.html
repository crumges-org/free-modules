✨ Key Features

Everything you need for flexible purchase price management

Bidirectional Price Sync

Edit Unit Price or Subtotal — the other field recalculates automatically. True two–way synchronization.

Real–time Onchange

Instant recalculation as you type. No need to save or refresh — values update on the fly via onchange events.

Editable Subtotal Field

The Subtotal field is made writable so you can enter a total amount and let the system derive the unit price.

Stored Inverse Computation

Uses Odoo's inverse mechanism on a stored computed field for reliable, persistent two–way data flow.

Zero Quantity Protection

Prevents division–by–zero errors with a clear user–friendly warning when quantity is zero.

Seamless Integration

Inherits the native Purchase Order Line model — no new tables, no configuration. Install and it just works.
