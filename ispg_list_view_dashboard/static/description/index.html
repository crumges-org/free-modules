⚙ HOW IT WORKS

Three Steps. XML Code.

1

Add the tag

Insert a <listdashboard> block inside any list view, directly or via xpath.
2

Define cards

Each <card> gets a title, a domain, and optionally a measure, colour and icon.
3

Done

The KPI ribbon appears above the list, live and clickable. Nothing else to configure.

 
<!-- Add inside any <list> view (directly or via xpath) -->
<listdashboard>
    <rowcard string="Order Status">
        <card string="Quotations" domain="[('state','=','draft')]"
              color="#0dcaf0" icon="fa-file-text-o"/>
        <card string="Sold" domain="[('state','=','sale')]"
              color="#198754" icon="fa-check-circle-o"/>
    </rowcard>
    <rowcard string="Revenue">
        <card string="Total Revenue" domain="[('state','=','sale')]"
              measure="amount_total" aggregate="sum" symbol="$"
              icon="fa-line-chart"/>
    </rowcard>
</listdashboard>

☰ REFERENCE

Tags & Attributes.

Tag / Attribute Purpose
<listdashboard> Wraps the whole ribbon. Cards can sit directly inside it (single row) or be grouped in <rowcard> blocks.
<rowcard string="..."> One horizontal row of cards; rows stack vertically. The optional string shows as a heading above the row.
string Card title shown above the value.
domain Odoo domain selecting the records to count or measure.
measure Numeric field to aggregate. Omit it to show a record count instead.
aggregate sum · avg · max · min (default sum).
symbol Unit / currency prefix, e.g. $ or €.
icon A FontAwesome class (fa-line-chart) OR an image URL/path (png/svg/jpg) — auto-scaled.
color Any CSS colour (hex / name / rgb). Omit for an automatic palette colour.
✎ SETUP

User Guide

List View KPI Dashboard — Installation & Usage

Install the module — it depends only on web, so it works with any Odoo edition. There is nothing to configure: simply add a <listdashboard> block inside any list (tree) view, either directly in the view or through an inherited xpath.

Inside it, add one <card> per KPI — give it a title and a domain, and optionally a measure (with sum / avg / max / min), a colour, an icon and a currency symbol. Group cards into rows with <rowcard>. Save the view and the clickable KPI ribbon appears above your records, recomputing live with the user's search filters.
