Overview

The Login Audit Log module offers real-time tracking and logging of user login sessions in Odoo. Designed for administrators and security-focused businesses, it allows you to:

  • Capture login details such as IP address, session ID, device type, browser, and operating system.
  • Monitor login activity with timestamps, timezone, and language preferences.
  • Identify administrative access and logins across different companies/databases.
Ideal for organizations that require traceable login history, internal security audits, and user activity tracking across Odoo environments.

Features

Track every user login in real time.

Log IP address, browser, OS, and device type.

Capture timezone, language, and session ID.

Detect and log login source company (multi-company support).

Clean, sortable login history model for administrators.

Fully compatible with Odoo Enterprise & Community.
