Best Practices

  • Use conditional logic to keep forms short and focused — higher completion rates follow.
  • Embed the JavaScript widget for inline forms and use iframe for isolated or full-page forms.

  • Enable reCAPTCHA on public forms and use secure tokens for partner or third-party embeds.
