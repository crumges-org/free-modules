|  About This Module

A powerful Odoo module that adds QR code generation, preview, and label printing capabilities to your maintenance equipment records. Instantly generate unique equipment codes, preview QR codes directly on the form, and print professional labels in multiple layouts — making equipment identification, tracking, and auditing effortless.

Whether you manage a small office, a large warehouse, or a multi-site facility, this module helps maintenance teams quickly identify and access equipment records by simply scanning a QR code with any mobile device.

 Built & maintained by SDLC Corp — trusted Odoo development partner worldwide.

|  Complete Feature Set

Everything you need to generate, preview, print, and scan QR codes — all within Odoo.

 QR Code Generation

  • Equipment Code field, auto-generated via sequence (e.g., MEQ/2026/00003)
  • Generate Code button to create a unique code on demand
  • Automatic code generation for new records
  • Configurable sequence prefix and numbering

 Preview & Printing

  • QR Code tab on equipment form — live QR preview
  • Equipment QR Label button for one-click printing
  • Multiple layouts: Dymo, 2x7, 4x7, and Custom
  • Configurable label header color for branding

 Scan & Access

  • Scannable QR codes link directly to equipment in Odoo
  • Works with any QR scanner or phone camera
  • Labels include QR code, equipment code, and name
  • Company header on labels for professional look

 Seamless Integration

  • Clean integration with standard Odoo Maintenance
  • No additional dependencies beyond Maintenance
  • Compatible with Odoo 18
  • Lightweight — zero performance overhead

After installation:

|  Frequently Asked Questions

 Works with existing equipment?

Yes. Generate QR codes for both new and existing records. Just click Generate Code.

 What label layouts are supported?

Dymo, 2x7 grid, 4x7 grid, and custom layouts to fit any printer.

 Can I scan with my phone?

Yes. Any QR scanner or phone camera opens the equipment record directly in Odoo.

 Requires extra modules?

No. Only depends on standard Odoo Maintenance. No extra dependencies.

 Custom label header color?

Yes. The print wizard lets you set a custom header color to match your branding.

 Compatible with Odoo 18?

Yes. Built for Odoo 18 and integrates cleanly with standard Maintenance.
