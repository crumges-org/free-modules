Voice Chatter Note

Record and attach voice notes directly inside Odoo chatter

Why It Matters

Typing long internal notes takes time. With Voice Chatter Note, users can instantly record audio messages directly from the chatter and attach them to any record.

Perfect for quick updates, field sales feedback, internal communication, and faster CRM follow-ups.

Key Features

  • 🎙 One-click voice recording inside chatter
  • ⏺ Live recording timer with Stop control
  • 📎 Automatic attachment as audio file (.webm)
  • ▶ Built-in audio preview player
  • 🗑 Delete option for recorded notes
  • 🔐 Works with Odoo access rights
  • 🌐 Compatible with CRM, Contacts, Sales, Helpdesk & more

How It Works

  1. Click the Record button in chatter
  2. Speak your message
  3. Click Stop when finished
  4. The voice note is automatically attached to the record
  5. Play, download, or delete anytime

Recording in Action

Use Cases

  • Sales reps sending quick deal updates
  • Managers leaving verbal instructions
  • Support teams logging call summaries
  • Field staff adding instant job site notes

No External Setup Required

Works directly in the browser using secure Web Audio APIs. No third-party services required.
