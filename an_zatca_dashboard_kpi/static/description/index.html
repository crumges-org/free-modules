ZATCA Dashboard KPIs

Display ZATCA submission status KPIs on Accounting Dashboard

Screenshot

Overview

This module adds ZATCA (Zakat, Tax and Customs Authority) submission status KPIs at the top of the Odoo Accounting Dashboard. Get a quick overview of your e-invoicing compliance status without navigating away from the main dashboard.

Use Case: Saudi Arabian companies using ZATCA e-invoicing can instantly see their submission status - how many invoices are sent, pending, have errors, or warnings - directly from the accounting dashboard.

Key Features

✔ Sent Invoices Counter - Track successfully submitted invoices to ZATCA
✔ Pending Invoices Counter - Monitor invoices awaiting ZATCA submission
✔ Error Invoices Counter - Quickly identify invoices with submission errors
✔ Warning Invoices Counter - View invoices submitted with warnings
✔ Clickable KPIs - Click any counter to view filtered invoice list
✔ Company-wide Statistics - Aggregates data across all sale journals

How It Works

Step 1: Install the module on your Odoo instance with l10n_sa_edi
Step 2: Navigate to Accounting Dashboard
Step 3: View ZATCA status KPIs at the top of the dashboard
Step 4: Click any KPI to view the filtered list of invoices
